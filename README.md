# Cross-Browser Hotel Booking UI Component Library

Vue + TypeScript component-library demo with reusable booking controls.

## Run
```bash
npm install
npm run dev
```
Open `http://localhost:55001`.

## Components
The source includes reusable date picker, guest filter, hotel card and modal components. Add additional components under `src/components/` following the same prop/event pattern.

## Testing
```bash
npm test
```

The project is structured as a portfolio/demo implementation; browser validation can be performed with Chrome, Firefox and Safari after installing dependencies.
